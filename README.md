# Brazilian E-Commerce Sales Analysis & Forecasting

## Project Overview
This project analyzes Brazilian e-commerce sales data using Power BI, Python, DAX, and Facebook Prophet.

## Features
- Sales Trend Analysis
- Customer Demand Analysis
- Payment Method Insights
- Forecasting Dashboard
- Interactive Visualizations

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Python
- Prophet
- Pandas
- Matplotlib

## Forecasting
Sales forecasting was performed using Facebook Prophet to predict future sales trends.

## Dataset
Brazilian E-Commerce Public Dataset by Olist.
